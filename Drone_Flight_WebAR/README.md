# Пілот — жестово-голосовий WebAR-тренажер

Самостійний статичний вебпроєкт. У ZIP корінь уже містить index.html; витягніть архів у окремий репозиторій або каталог розгортання.

## Запуск

Потрібен HTTPS-хостинг або localhost для доступу до камери. Інтернет потрібен для завантаження A-Frame, MediaPipe Tasks Vision і моделі руки. Найпростіше: GitHub Pages (Publish from branch, корінь репозиторію) або Cloudflare Pages (статичний каталог без build-команди). Відкрийте адресу на ноутбуці чи телефоні, натисніть «Камера + руки» і дозвольте доступ.

Голос Web Speech API доступний не в кожному браузері та може використовувати мережеве розпізнавання. Якщо він недоступний, усі важливі дії дублюються кнопками та клавішами. Рекомендований браузер: актуальний Chrome/Edge.

## Керування

- Долоня вертикально перед камерою, пальці догори. Рука ліворуч/праворуч від калібрувального центра керує креном; рух угору/вниз — тангажем; нахил кисті у площині кадру — рисканням.
- Щіпка вимірюється як відстань P4–P8, поділена на розмір долоні P0–P9. Після калібрування закритий pinch знижує висоту, середнє положення відповідає зависанню, відкритий pinch підіймає.
- Калібрування триває 6 секунд: нейтральна рука/середня щіпка, зімкнути кінчики, комфортно розвести кінчики.
- Кулак утримати 0,7 с — пауза; V-поза 0,7 с — змінити вид; розкрита долоня 0,7 с — продовжити.
- Клавіші: W/S або ↑/↓ — тангаж; A/D або ←/→ — крен; Q/E — рискання; R/F — висота; Space — пауза; 1/2/3 — FPV/chase/тренувальний split; M — голос.
- Режими маршруту: безперервний вільний політ, кільця, цілі. Обмеження швидкості задається повзунком.

## WebAR та обмеження

Кнопка «Камера-фон» додає камеру позаду віртуальної сцени як pass-through накладення. Це не SLAM і не прив'язка до площини: для тренування використовуйте синтетичну 3D-місцевість, а камеру-фон — як демонстрацію накладення. Це програмний симулятор, не сертифікований тренажер реального БПЛА.

У файлі app.js можна змінити версію MediaPipe CDN і модель; якщо змінюєте tasks-vision, оновлюйте однаковий номер у посиланні модуля та каталогу WASM у hands.js.
