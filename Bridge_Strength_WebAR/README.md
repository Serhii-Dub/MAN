# МістЛаб — симулятор балок і мостів

Самостійний статичний вебпроєкт. Розпакуйте ZIP так, щоб `index.html` лежав у корені репозиторію. Розгортання на GitHub Pages або Cloudflare Pages не потребує VPS чи команди збірки.

## Запуск

Розрахункова схема працює відразу без камери. Для жестів відкрийте сайт через HTTPS або `localhost`, натисніть **«Увімкнути камеру руки»** й потримайте долоню в центрі маленького вікна приблизно 2 секунди. Камера не виводиться поверх мосту: вона використовується тільки для відстеження долоні.

Голос запускається окремо кнопкою **«Увімкнути голос»**. Потрібен браузер з Web Speech API та інтернетом; якщо голос недоступний, використовуйте повзунки, кнопки або клавіатуру.

## Налаштування моделі

1. Оберіть балку, ферму Воррена або арковий міст.
2. Задайте матеріал і профіль.
3. Вкажіть проліт, висоту ферми/арки, сценарій і загальну силу.
4. Пересувайте вантаж повзунком, кнопками або рукою. Кнопка **«Нескінченний прогін»** безперервно веде рухомий вантаж через міст; можна змінювати тип мосту, матеріал, розміри й силу, поки він рухається.
5. Дивіться на прогин, напруження, згинальний момент або силу в стрижнях та кольоровий індикатор навчальної межі.

Сценарії руху: один вантаж, двовісний автомобіль, тривісна будівельна техніка та тривісна вантажівка з матеріалами. **«Рівномірний шар матеріалів»** означає пісок, щебінь або покриття, розкладені по всьому прольоту. Це постійне нерухоме навантаження, тому воно не їде під час прогону.

## Жести й кнопки

- Долоня до камери, пальці догори. Рух ліворуч/праворуч переміщує вантаж по мосту.
- Долоня до камери, пальці догори. Кінчики великого й вказівного пальців торкаються — 0 кН; розведіть до відстані від зап’ястя до основи середнього пальця — сила зросте до 900 кН. Це відносний сигнал, а не вимірювання реальної сили.
- Кулак зупиняє прогін, відкрита долоня запускає або продовжує його, V-поза перемикає балку → ферму → арку. Для цього увімкніть **«Жести-команди»**.
- Кнопки ←/→ пересувають вантаж, ↑/↓ змінюють силу, Space запускає або зупиняє прогін, M вмикає/вимикає голос.
- **Плавно рукою**, **Жести-команди** та **Голос uk-UA** працюють окремо; пресети **«Лише жести»** та **«Комбіноване»** вмикають готові поєднання.

## Голосові команди

Система приймає числові цифри або українські числівники. Приклади:

- Тип: «балка», «ферма», «арка».
- Матеріал: «сталь», «алюміній», «деревина».
- Сценарій: «автомобіль», «будівельна техніка», «вантажівка з матеріалами», «рівномірний шар», «точковий вантаж».
- Числа: «проліт 40» або «проліт сорок»; «висота 8»; «сила 500» або «навантаження п'ятсот»; «позиція 70 відсотків».
- Прогін: «старт», «почати симуляцію», «прогін навантаження», «стоп», «пауза».

## Розрахункова модель

Балка рахується як проста оперта балка з суперпозицією точкових навантажень. Ферма й арка — мала плоска стрижнева модель, розв’язана методом матриці жорсткості. Деформацію на схемі збільшено для видимості. Не моделюються місцева стійкість, втома, зсув, динамічні ефекти, фундаменти та будівельні норми. Це навчальне порівняння форм, не розрахунок безпеки реального мосту.

Схема малюється Canvas 2D: це прибирає постійний WebGL-рендер і помилки геометрії з консолі та дає легший інтерфейс для слабших пристроїв. Це браузерний навчальний симулятор, а не накладання 3D-моста на реальне зображення кімнати. Камера використовується тільки для руки.
