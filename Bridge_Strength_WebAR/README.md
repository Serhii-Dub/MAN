# МістЛаб — WebAR-симулятор міцності мостів

Самостійний статичний проєкт. Корінь ZIP містить index.html; розгортайте його окремо від симулятора дрона.

## Запуск і публікація

Працює як статичний сайт: GitHub Pages з кореня репозиторію або Cloudflare Pages без build-команди. Для камери потрібен HTTPS або localhost; MediaPipe та модель руки завантажуються з CDN, тому потрібен інтернет. Рекомендований браузер — актуальний Chrome/Edge. Якщо SpeechRecognition недоступний, користуйтеся кнопками та клавіатурою.

## Що моделюється

- Балковий міст: шарнірно-роликова балка, довільне точкове/осьове/рівномірне навантаження, суперпозиція прогину та моментів.
- Ферменний міст: трикутна ферма Воррена, 2D метод жорсткості стрижнів.
- Арковий міст: параболічні ребра, підвіски та розкоси, 2D метод жорсткості.
- Навантаження: окремий вантаж, двовісний автомобіль, тривісна будівельна техніка або матеріали, рівномірно розподілені по прольоту.
- Профілі: прямокутний переріз, кругла порожниста труба, двотавр. Матеріали: навчальні орієнтовні параметри сталі, алюмінію, деревини.
- Положення/силу можна змінювати повзунками, екранними кнопками, клавішами, жестами або голосом. Кнопки працюють без камери та мікрофона.

## Жести й голос

Покажіть долоню до камери вертикально. Після калібрування рух руки вліво/вправо пересуває вантаж; щіпка керує силою від 0 до Fmax. Закритий щіпок — нуль, відкритий — максимальна сила. Кулак, утриманий 0,7 с, знімає навантаження; V-поза перемикає тип мосту. Голосові приклади: «балка», «ферма», «арка», «автомобіль», «будівельна техніка», «матеріали», «сталь», «алюміній», «деревина», «навантаження п'ятсот», «скинути».

## Точність і межі

Для балки використовується лінійно-пружна формула прогину простої опертої балки з точковими силами та суперпозиція. Для ферми й арки вирішується мала 2D стрижнева система методом матриці жорсткості; матеріал вважається однорідним, з'єднання шарнірними, місцева стійкість, втома, зсув, динаміка, фундамент та реальні норми не моделюються. Геометричний прогин у сцені збільшено приблизно у 30 разів, а цифри залишаються розрахунковими.

«Камера pass-through» — накладення моделі на відео, без SLAM/plane tracking та без вимірювання столу. Це навчальний симулятор; результати не є розрахунком безпечності реальної споруди.
